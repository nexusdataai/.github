# nexusdataai/.github

Organization-wide defaults and the **public profile** for [nexusdataai](https://github.com/nexusdataai) on GitHub.

## Layout

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | Renders on the org **Overview** tab (organization profile README). |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contribution guidelines for org repos (when not overridden). |
| [`SECURITY.md`](SECURITY.md) | Security reporting defaults for the org. |

## Publishing the profile

1. Merge changes to the **default branch** of this repository (usually `main`).
2. Ensure this repo is **public**.
3. On the org **Overview**, use **View as: Public** to verify rendering.

## Related documentation

Product and engineering documentation lives in **[nexus-docs](https://github.com/nexusdataai/nexus-docs)** (MkDocs). The profile README is a short index; detailed docs stay in that repo.
